# Retail Sales Analysis Using SQL

## Overview
This project analyzes retail sales data using MySQL to uncover business insights related to revenue, customer behavior, and product performance.

## Dataset
- 1000 retail transactions
- Customer demographics
- Product categories
- Sales information

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- Subqueries
- CASE Statements
- Window Functions

## Key Insights
- Revenue analysis
- Product category performance
- Customer segmentation
- Monthly sales trends

## Tools
- MySQL Workbench
- SQL
